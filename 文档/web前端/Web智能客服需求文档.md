# Web 智能客服需求文档

## 1. 项目背景

当前智能客服后端主链路已经打通，能够完成知识库问答、订单类 MCP 查询、回答可靠性判断以及无法回答时的转人工处理。

目前缺少一个可以直接给用户使用和展示的 Web 页面，因此这一阶段只需要补一个简洁的客服前端，把现有后端能力真正展示出来。

## 2. 要做什么

实现一个单页面 Web 智能客服界面，页面只保留主体功能：

- 顶部：项目名称、智能客服在线状态、转人工入口。
- 左侧：快捷服务入口，包括在线咨询、查订单、查物流、退换售后。
- 中间：主要聊天区域，用于展示用户问题和 AI 客服回答。
- 底部：消息输入框和发送按钮。

聊天区域需要支持三类结果：

1. **知识库问答**
   - 用户咨询退款、物流、活动规则等问题。
   - 前端正常展示 AI 回复。

2. **订单 / 物流查询**
   - 用户输入订单号后，展示 MCP 返回的订单或物流结果。
   - 结果可以使用简洁卡片展示订单号、状态、物流状态等信息。

3. **无法回答**
   - 当后端判断无法可靠回答时，前端提示用户转人工客服。
   - 不向用户展示 RAG、MCP、Rerank 等内部技术信息。

## 3. 输出什么结果

完成后，用户可以直接在浏览器中：

- 输入问题并发送；
- 查看 AI 客服回复；
- 查询订单或物流信息；
- 查看结构化订单结果；
- 在系统无法回答时看到转人工提示。

页面整体保持简洁，只保留客服使用所需的核心内容。

## 4. 做到什么可以结束

满足以下条件后，本阶段结束：

- Web 页面可以正常打开；
- 可以调用现有 FastAPI `/chat` 接口；
- 知识库问题可以正常回答；
- 订单类问题可以正常展示 MCP 查询结果；
- 无法回答的问题可以显示转人工提示；
- 页面布局完整，能够作为项目演示页面使用。

完成以上内容后，不继续增加登录、商城、后台管理、数据统计等功能。
