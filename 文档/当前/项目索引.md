# 项目索引（临时）

> 本索引只覆盖可运行代码、配置、资料、脚本、测试和评测对象。按当前执行口径，`文档/` 与 `review/` 的历史内容不盘点、不分类、不迁移；本文件只是本轮整理的临时导航。

## 主链入口

```text
HTTP: uvicorn app.main:app
  -> app/api/chat.py
  -> app/services/chat_service.py
  -> 普通 RAG / 模拟订单 / 闲鱼专家编排

闲鱼渠道: scripts/run_xianyu_stage3.py
  -> app/channels/xianyu/stage3_worker.py
  -> HTTP /chat 或人工接管
```

### app/main.py

[打开源文件](../../app/main.py)

职责：创建 FastAPI 应用，挂载聊天与渠道控制路由，并提供 `/health`、`/ready`。
谁调用：`uvicorn app.main:app`、HTTP 服务进程。
继续调用：`app/api/chat.py`、`app/api/conversations.py`、普通 RAG 就绪检查。
不负责：摄取资料、直接连接闲鱼 WebSocket、批准自动发送。
当前状态：正式 HTTP 入口，保留。

### app/api/chat.py

[打开源文件](../../app/api/chat.py)

职责：定义 `/chat` 请求与响应模型，将请求交给 `ChatService`。
谁调用：`app/main.py` 挂载的 HTTP 路由。
继续调用：`app/services/chat_service.py`。
不负责：决定知识库路径或执行渠道发送。
当前状态：正式 API 边界，保留。

### app/services/chat_service.py

[打开源文件](../../app/services/chat_service.py)

职责：统一编排普通 RAG、模拟订单和闲鱼商品/专家问答，并维护会话上下文。
谁调用：`app/api/chat.py`，也被渠道 `ChatApiClient` 间接调用。
继续调用：`RAGService`、`MCPService`、订单路由、商品服务、闲鱼专家编排和会话管理。
不负责：直接收发 WebSocket 消息或读写渠道控制库。
当前状态：HTTP 问答主链，保留。

### app/services/xianyu/expert_orchestrator.py

[打开源文件](../../app/services/xianyu/expert_orchestrator.py)

职责：按查询计划协调闲鱼商品、服务与价格专家，合并可答复、澄清或转人工结果。
谁调用：`ChatService`。
继续调用：`ItemContextResolver`、`ProductAgent`、`ServiceAgent`、`PriceAgent`、响应构造器。
不负责：渠道消息去重或平台发送。
当前状态：闲鱼专家主链，保留。

### scripts/run_xianyu_stage3.py

[打开源文件](../../scripts/run_xianyu_stage3.py)

职责：受控启动闲鱼渠道循环，并在启用前检查参考代码、账号控制与 S6 验收报告。
谁调用：人工命令行启动。
继续调用：事件适配器、`XianyuStage3Worker`、渠道库、HTTP 客户端、发送器与通知器。
不负责：重新定义 `/chat` 的业务策略。
当前状态：正式渠道运行入口，保留。

### app/channels/xianyu/stage3_worker.py

[打开源文件](../../app/channels/xianyu/stage3_worker.py)

职责：协调一条闲鱼消息，从接收检查、调用后端到发送、澄清或接管。
谁调用：`scripts/run_xianyu_stage3.py` 的消息循环。
继续调用：`ChannelStore`、`ConversationGuard`、`ChatApiClient`、动作映射、发送器或通知器。
不负责：决定商品事实、自由议价或加载全部知识文件。
当前状态：正式渠道主链，保留。
